    DIVE MANUAL

    How to play

    1. 1You get five rounds, each with a different kind of prompt.
    2. 2Type a level name and submit. GDBrowser checks it against the prompt. Each hint points at a valid example.
    3. 3The rarer the level — fewer downloads and likes — the higher the round score, up to 100.
    4. 4Each level can only be used once per run. Your final score is the average of all five rounds.
    QUESTION TYPES

    A run mixes Difficulty (name a level of that difficulty), Song (name a level using the named track — the hint gives one), Demon List (any demon on the current top-100 community list), and Level Traits like length, star rating, featured/epic/legendary, two-player, game version and user coins.

    SCORING

    Rarity uses a softened logarithmic curve with the same boundaries as the beta: 2,000 → 100,000,000 downloads and 1 → 4,000,000 likes. A level at the bottom of a range scores 100; one at the top scores 0, but the middle is far more forgiving. Download and like rarity are averaged for the round score.
